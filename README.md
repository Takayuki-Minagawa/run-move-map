# 🗾 日本縦断チャレンジ

走行距離・歩行距離を記録して、日本地図上を沖縄から北海道まで旅するWebアプリケーションです。

![Version](https://img.shields.io/badge/version-2.0.3-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![PWA](https://img.shields.io/badge/PWA-ready-purple)

## 🎯 概要

毎日のランニングやウォーキングの距離を記録すると、累計距離に応じて日本地図上を移動していきます。沖縄・那覇をスタートし、約3,000kmの旅を経て北海道・札幌を目指しましょう！

## ✨ 主な機能

### 📝 距離記録
- 日付・距離・種別（ランニング/ウォーキング）を入力
- 過去の日付も記録可能
- 履歴の一覧表示・削除
- 📝 一言メモ機能
- 📷 写真添付機能

### 🗺️ 地図表示

### ☁️ クラウドバックアップ（v2.0.3 新機能）
- **保存先の自由選択**: File System Access API により、Google Drive・OneDrive・ローカル等の任意のファイルを保存先に指定
- **起動時チェック**: キャッシュが空でバックアップに記録がある場合、自動復元を提案
- **自動バックアップ**: 記録の追加・削除・インポートのたびにサイレント書き込み
- **手動バックアップ / 手動復元**: 設定タブからいつでも実行可能
- **保存先変更 / クリア**: IndexedDB にハンドルを永続保存し、いつでも変更可能
- 非対応ブラウザ（Firefox / Safari）では従来の手動エクスポート/インポートにフォールバック

- **自動保存**: LocalStorageによる永続化

- **インポート**: バックアップからの復元
- **リセット**: 全データの初期化（確認付き）

## 🚀 使い方

### ローカルでの起動

```bash
# リポジトリのクローン
git clone <repository-url>
cd run-move-map

# ローカルサーバーを起動（Python 3）
python3 -m http.server 8080

# または Node.js の場合
npx serve .

# ブラウザで開く
open http://localhost:8080
```

### 基本操作

1. **記録する**: 日付・距離・種別を入力して「記録する」ボタンをクリック
2. **確認する**: 地図上の現在地と進捗バーで状況を確認
3. **履歴を見る**: 「📜 履歴」タブで過去の記録を確認
4. **バッジを確認**: 「🏅 バッジ」タブで獲得状況をチェック
5. **バックアップ設定**: 初回起動時にバックアップ保存先ダイアログが表示されます
   - Google Drive / OneDrive 等の同期フォルダ内のファイルを指定することを推奨
   - 設定後は記録変更のたびに自動保存されます
6. **手動バックアップ / 復元**: 「⚙️ 設定」タブの「バックアップ保存先」カードから実行

## 🔧 カスタマイズ

### ルートの変更
`js/routes.js` の `ROUTE_DATA.cities` 配列を編集して、都市の追加・削除・順序変更が可能です。

### バッジの追加
`js/achievements.js` の `BADGES` 配列に新しいバッジオブジェクトを追加できます。

```javascript
{
  id: 'custom_badge',
  name: 'カスタムバッジ',
  description: '条件を達成',
  icon: '🎯',
  condition: (data) => data.totalDistance >= 500,
  category: 'distance'
}
```

### テーマカラーの変更
`css/style.css` の `:root` 内のCSS変数を変更してテーマをカスタマイズできます。

```css
:root {
  --primary-color: #ff6b6b;  /* メインカラー */
  --secondary-color: #4ecdc4; /* アクセントカラー */
  --success-color: #6bcb77;   /* 成功カラー */
}
```
