# 🗾 日本縦断チャレンジ

走行距離・歩行距離を記録して、日本地図上を沖縄から北海道まで旅するWebアプリケーションです。

![Version](https://img.shields.io/badge/version-2.1.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![PWA](https://img.shields.io/badge/PWA-ready-purple)

## 🎯 概要

毎日のランニングやウォーキングの距離を記録すると、累計距離に応じて日本地図上を移動していきます。沖縄・那覇をスタートし、約3,000kmの旅を経て北海道・札幌を目指しましょう！

## ✨ 主な機能

### 📝 距離記録
- 日付・距離・種別（ランニング/ウォーキング）を入力
- 過去の日付も記録可能
- 履歴の一覧表示・削除
- 📝 一言メモ機能
- 📷 写真添付機能

### 🗺️ 地図表示
- SVGによる日本地図のインタラクティブ表示
- 累計距離に応じてルートが赤く伸びる
- 現在地マーカーのパルスアニメーション
- 到達済み都市のハイライト表示

### 🎉 達成イベント
- **都市到達イベント**: 新しい都市に着くとお祝いモーダル＋紙吹雪
- **都市別テーマ演出**: 都市ごとの色・モチーフで紙吹雪を表示
- **ご当地豆知識**: 各都市の名所・名物を紹介
- **ゴール演出**: 日本縦断達成時の特別演出

### ✨ 旅を楽しむ機能（v2.1 新機能）
- **距離のおもしろ換算**: フルマラソン、東京〜大阪往復、地球一周、富士山の標高に換算
- **到着予測**: 直近28日のペースから次の都市と札幌への到着日を予測
- **現在地リンク**: 都市間を補間した現在地をGoogleマップ／ストリートビューで表示
- **今日のミッション**: 日付シードで毎日変わる、保存不要のミニお題
- **1年前の今日**: 過去の記録とメモをフォーム付近に表示
- **旅のリプレイ**: 記録を時系列で地図上にアニメーション再生

### 💌 コレクション・遊び（v2.1 新機能）
- **絵はがきコレクション**: 到達都市の名所、豆知識、逆算した到達日を表示
- **御朱印帳**: 到達済み／未到達の全14都市を和風スタンプで一覧化
- **ご当地クイズ**: 到達した都市ごとに3択問題を解放
- **ゴーストペーサー**: 開始日と1日ペースを設定し、仮想旅人と距離を比較
- **年間振り返り**: 年間距離、最長日、最多月、種別、バッジを5枚のカードで再生
- **進捗シェアカード**: CanvasでPNGを生成し、保存またはWeb Share APIで共有

### 🎨 季節・サウンド（v2.1 新機能）
- 記録月に応じて地図へ桜・波・紅葉・雪を表示
- Web Audio APIで記録音・都市到達ファンファーレをコード生成
- どちらも設定タブからON/OFF可能

### 📊 統計・グラフ機能（v2.0 新機能）
- 週間距離バーグラフ
- 月間推移グラフ
- 種別（ラン/ウォーク）円グラフ
- 累計距離折れ線グラフ
- 曜日別平均レーダーチャート

### 📅 カレンダー機能（v2.0 新機能）

## 🚀 使い方

### ローカルでの起動

```bash
# リポジトリのクローン
git clone <repository-url>
cd run-move-map

# ローカルサーバーを起動（Python 3）
python3 -m http.server 8080

# または Node.js の場合
npx serve .

# ブラウザで開く
open http://localhost:8080
```

### 基本操作

1. **記録する**: 日付・距離・種別を入力して「記録する」ボタンをクリック
2. **確認する**: 地図上の現在地と進捗バーで状況を確認
3. **履歴を見る**: 「📜 履歴」タブで過去の記録を確認
4. **バッジを確認**: 「🏅 バッジ」タブで獲得状況をチェック
5. **旅を楽しむ**: 統計・バッジ・目標・ルート・ソーシャルの各タブでv2.1機能を利用
6. **バックアップ / 復元**: 「⚙️ 設定」タブからJSONをエクスポート／インポート

## 📊 データ構造

### LocalStorage保存形式

```json
{
  "totalDistance": 1234.5,
  "records": [
    {
      "id": 1706659200000,
      "date": "2026-01-31",
      "distance": 5.0,
      "type": "run",
      "createdAt": "2026-01-31T10:00:00.000Z"
    }
  ],
  "earnedBadges": ["distance_100", "streak_7"],
  "reachedCities": ["okinawa", "kagoshima", "kumamoto"],
  "streakDays": 7,
  "lastRecordDate": "2026-01-31",
  "stats": {
    "totalRunDistance": 800.0,
    "totalWalkDistance": 434.5,
    "totalRecords": 50,
    "longestStreak": 14
  },
  "settings": {
    "seasonFx": true,
    "sound": true,
    "ghost": {
      "enabled": false,
      "startDate": "2026-01-01",
      "dailyPace": 5
    }
  },
  "createdAt": "2026-01-01T00:00:00.000Z",
  "updatedAt": "2026-01-31T10:00:00.000Z"
}
```

v2.1で追加される設定は既存の `settings` オブジェクト内だけに保存されます。換算、予測、コレクション、クイズ、振り返りなどはすべて既存データから都度計算され、保存形式を増やしません。

## 🔧 カスタマイズ

### ルートの変更
`js/routes.js` の `ROUTE_DATA.cities` 配列を編集して、都市の追加・削除・順序変更が可能です。

### バッジの追加
`js/achievements.js` の `BADGES` 配列に新しいバッジオブジェクトを追加できます。

```javascript
{
  id: 'custom_badge',
  name: 'カスタムバッジ',
  description: '条件を達成',
  icon: '🎯',
  condition: (data) => data.totalDistance >= 500,
  category: 'distance'
}
```

### テーマカラーの変更
`css/style.css` の `:root` 内のCSS変数を変更してテーマをカスタマイズできます。

```css
:root {
  --primary-color: #ff6b6b;  /* メインカラー */
  --secondary-color: #4ecdc4; /* アクセントカラー */
  --success-color: #6bcb77;   /* 成功カラー */
}
```
